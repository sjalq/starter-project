# Working in this repository

This is a Lamdera (Elm) application template. Read `.cursor/rules/lamdera.mdc` for architecture and coding conventions, and `.cursor/rules/elm-functions.mdc` for an index of every function in `src/` (regenerated by `./compile.sh`).

Always use `http://localhost:8000` (not `0.0.0.0`) to reach `lamdera live`.

## Build, test, review

```bash
./compile.sh                                  # function index + tests + compile (npm run build)
elm-test-rs --compiler lamdera                # tests only (npm test)
npm run review                                # elm-review
```

Run `npm install` once for elm-review. Use `elm-test-rs`, not `elm-test`: only `elm-test-rs --compiler lamdera` can compile Lamdera's codecs. It discovers every exposed `Test` in `tests/`, so do not add an aggregating `Tests.elm` (it would run every suite twice).

If compilation fails with errors about `Types.w3_encode_*`, run `./reset.sh` to clear the compiler cache.

## Tests

```
tests/
  Program/          End-to-end tests with lamdera/program-test (Effect.Test)
  Property/         Property and unit tests for pure modules
  Fuzzers/          Shared fuzzers
  Helpers/          Simulation config (Helpers.Simulation) and test models
  Protocol.elm      Generated by tools/wire-extractor, do not edit
  ProtocolWireProof.elm
  TestViewer.elm    Visual snapshot viewer
```

`tests` is listed in `elm.json` `source-directories` so `lamdera make tests/TestViewer.elm` can build the viewer; keep test-only module names distinct from app modules.

Program test shape:

```elm
Sim.start "examples page shows the clipboard card"
    [ Test.connectFrontend 0
        (Effect.Lamdera.sessionIdFromString "session-1")
        "/examples"
        { width = 1920, height = 1080 }
        (\frontend ->
            [ frontend.checkView 100 (Query.has [ text "Clipboard Example" ])
            , frontend.update 100 ToggleDarkMode
            , frontend.checkModel 100 (\model -> if model.preferences.darkMode then Err "still dark" else Ok ())
            , frontend.portEvent 100 "clipboard_from_js" payload
            ]
        )
    , Test.checkBackend 100 (\backend -> Ok ())
    ]
    |> Test.toTest
```

Program-test only simulates `Effect.*` commands. Anything wrapped in `Command.fromCmd` (raw `Cmd`, e.g. `Lamdera.sendToBackend`, `Random.generate`) runs in the real app but is silently skipped in tests, so new code should use `Effect.Lamdera`, `Effect.Task`, `Effect.Time`, `Effect.Http`, `Effect.Command.sendToJs` and `Effect.Subscription.fromJs`.

Visual viewer: `./scripts/run-test-viewer.sh`, then open <http://localhost:8888/viewer.html>. Use `frontend.snapshotView 100 { name = "..." }` in `tests/TestViewer.elm`.

## Wire protocol

`ToBackend` and `ToFrontend` are frozen by `tests/Protocol.elm` and `tests/ProtocolWireProof.elm`. After an intentional change to either type, regenerate them:

```bash
PATH="$PWD/scripts/bin:$PATH" node tools/wire-extractor/bin/wire-extractor.js
```

`A String` (ToBackend) and `A0 String` (ToFrontend) must remain the alphabetically first constructors: the WebSocket client encodes them as tag 0, and `tests/Property/WebSocketWireTests.elm` enforces it.

## Permissions

Every `ToBackend` message goes through `Backend.updateFromFrontendCheckingRights`, which asks `Rights.Permissions.sessionCanPerformAction`. When you add a `ToBackend` constructor, add it to `Rights.Permissions.actionRoleMap` with the minimum role (`Anonymous`, `UserRole` or `SysAdmin`); the compiler will point you there.

## RPC endpoints

HTTP endpoints live in `src/RPC.elm` and are served at `/_r/{endpoint}`. Register a handler in `lamdera_handleEndpoints`:

```elm
"myEndpoint" ->
    LamderaRPC.handleEndpointJson myHandler args model
```

Handler signatures:

```
JSON:  SessionId -> BackendModel -> Headers -> Json.Value -> ( Result Http.Error Json.Value, BackendModel, Cmd BackendMsg )
Raw:   SessionId -> BackendModel -> HttpRequest -> ( RPCResult, BackendModel, Cmd msg )
```

Protect privileged endpoints with `RPC.isAuthorized request.headers` (checks `x-lamdera-model-key` against `Env.modelKey`; the development key is refused in Production). Request headers are redacted before RPC calls are logged.

Built-in endpoints: `getModel`, `setModel`, `getLogs` (all need the model key), and the async example pair `getPrice` / `getPriceResult`. For work that outlasts Lamdera's request timeout, follow `EndpointExample/Price.elm`: start a task chain with `AsyncRPC.handleTaskChain`, return a token, poll with `AsyncRPC.handlePollingResult`.

Always send a JSON body, even an empty one:

```bash
curl -X POST "http://localhost:8000/_r/getLogs" \
  -H "Content-Type: application/json" \
  -H "x-lamdera-model-key: 1234567890" \
  -d '{}'
```

## Logs

Backend `Logger.logInfo` / `logWarn` / `logError` / `logDebug` calls land in two places:

- `BackendModel.logState`: in-memory, capped at `Env.logSize`, shown at `/admin/logs` and returned by `/_r/getLogs`.
- Lamdera's disk-backed production log (every backend `Debug.log`). Read it with `node scripts/node/lamdera-logs.mjs read --lines 100`. See `LAMDERA-LOGS.md`.

`node scripts/node/lamdera-cli/index.js logs --env prod --follow` tails the in-memory log over RPC (install once with `npm ci --prefix scripts/node/lamdera-cli`, and configure `.lamdera-cli.json` from `.lamdera-cli.example.json`).

## Lamdera REPL

With `lamdera live` running, click "Show Repl" in the dev bar.

```
All tabs:          fem, setFem, updateFE, sendToBE, capture
Leader tab only:   bem, setBem, updateBE, sendToFE, broadcast
```

`fem` and `bem` always return the current value; use `capture bem` to take a snapshot. Examples:

```elm
> bem.users |> Dict.keys
> updateFE ToggleDarkMode
> sendToBE (EmailPasswordAuthToBackend (EmailPasswordLoginToBackend "admin@example.com" "admin"))
> setBem { bem | pollingJobs = Dict.empty }
```

From the shell: `lamdera backend --import='import Dict' --eval='Dict.size model.users'`.

## Evergreen migrations

Run `lamdera check` (or `lamdera deploy`) first so Lamdera generates the migration skeletons in `src/Evergreen/`, then edit the generated code.
